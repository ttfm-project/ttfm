# TTFM CLI Specification

## 1. 特殊な出力モード

### 1.1 シンプル出力モード (`--short` / `-s`)
`ttfm search` コマンドにおいて、`--short` オプションを指定することで、機械可読性の高い形式で結果を出力する。
- **フォーマット**: ヘッダーや装飾を排除し、1行につき1アイテム（またはプロジェクション結果）を出力する。
- **デフォルト挙動**: プロジェクション未指定時は `path` (ファイルの場合) または `name` を出力する。
- **プロジェクション時**: 指定されたプロジェクションの値のみをタブ区切りで出力する。
- **エラーハンドリング**: パイプ切断 (`EPIPE`/`SIGPIPE`) を検知し、パニックすることなく正常終了コードでプロセスを閉じる。

**例**:
```bash
# 特定の拡張子を持つファイルのパス一覧を head に渡す
ttfm search --short "extension:rs & path:" | head -n 5
```

### 1.2 ワイド出力モード (`--wide` / `-w`)
`ttfm search` コマンドにおいて、`--wide`（または `-w`）オプションを指定することで、端末幅によるカラム打ち切りを行わずに全カラムを出力する。
- **デフォルト挙動**: 端末幅に収まる範囲でランク降順にカラムを表示し、収まらない低ランクのカラムは右側に `...` として省略される。
- **ワイド出力**: 端末幅の制限を解除し、検索結果に含まれるすべてのタグ型カラムを展開して表示する。

## 2. 出力制御とパイプライン連携
コマンドラインツールとしての有用性を高めるため、他のLinuxコマンドとの連携をサポートする。

### 2.1 カラム表示幅とランク優先度
通常のテーブル表示では、カラム（タグ型）は ITEM.md §7 の通りランク降順で左から配置される。
- 全カラムが端末幅に収まらない場合でも、折り返し表示や全カラムの縮小表示は行わない。
- ランクの高いカラムから順に表示し、端末幅を使い切った時点で、以降のランクが低いカラムはそのまま表示範囲外とする（右端に `...` ヘッダーを表示）。
- 対話モードでは `ID` カラムのみが固定表示され、`>` / `<` による横スクロール表示が可能となる。

### 2.2 表示単位・フォーマット (`display_unit`)
型定義アイテムに `display_unit` が設定されている場合（`binary`, `si`, またはプラグイン/組み込みの `DisplayFormats` オプション）、CLI 出力時に指定された単位フォーマットに従って自動整形される。
- `binary`: 2進接頭辞（KiB, MiB, GiB 等）
- `si`: 10進接頭辞（KB, MB, GB 等）
- プラグイン/組み込み定義フォーマット: `display().formats().options` に定義されたカスタムフォーマット

## 3. データベースの初期化 (`ttfm clear`)
索引データを削除し、再構築可能な状態に戻すためのコマンド。
- `ttfm clear`: File Reference 関連のテーブル（`file_references` / `locations` / `base_tags` / `tags_by_location`）、`tags` の `origin=file`、`.index_complete` (STORE.md §1参照)を削除する。`tags` のその他の origin は残す。
  - 削除されたFileにユーザーが付与していたタグはSettling Itemとして保持される。
- `ttfm clear --all`: データベース全体を削除する。Origin を問わず全ての登録済みの Item が失われる。

## 4. タグ編集 (`ttfm tag`)
- `ttfm tag <SearchQuery> <EditQuery>`: 誤実行防止のため第2引数は必須。
- `ttfm tag <SearchQuery> ""` : 空文字指定で検索結果をそのままDBへ登録する（EDIT.md §5.7 参照）。

## 5. インタラクティブモード(`ttfm -i`)
対話型（fdisk モデル）で検索・タグ編集・詳細確認を継続的に実行するモード。

- **起動**: `ttfm -i [QUERY]`（初期クエリを省略した場合は `Init` 状態で起動）。
- **主要コマンド**:
  - `s <Query>`: 検索を実行し、結果一覧を表示して `Searched` 状態へ遷移。
  - `t "<Query>" <EditQuery>`: タグ付与・編集。第1引数はダブルクォートで囲み、直前クエリは Ghost Text から補完可能（`""` 指定で Stored 化）。第2引数全体がダブルクォートで囲まれている場合は外側クォートを除去。
  - `u "<Query>" <EditQuery>`: タグ削除。第1引数はダブルクォート必須。第2引数は外側クォート除去に対応。
  - `i <paths>...`: 指定パス（ディレクトリ等）のスキャンおよびインデックス作成・更新。
  - `n`: 検索結果の次ページ表示（次ページ存在時のみガイダンス表示）。
  - `p`: 検索結果の前ページ表示（前ページ存在時のみガイダンス表示）。
  - `>`: カラムの右スクロール（未表示カラム存在時のみ `show right` としてガイダンス表示）。`ID` カラムのみ固定され、右側のカラム群を表示する。
  - `<`: カラムの左スクロール（前カラム存在時のみ `show left` としてガイダンス表示）。
  - `clear [all]`: 索引データの削除（`-y` 未指定時は確認プロンプト表示）。
  - `h`: ヘルプ（TTQL/EDIT文法およびコマンド一覧）の表示。
  - `m`: メニュー（コマンド一覧）の表示。
  - `q`: 検索コンテキストのクリア（`Searched` から `Init` への復帰）。`Init` 状態での `q` で対話モード終了。
- **安全確認と整合性**:
  - 編集・消去時は `-y` / `--confirm never` が指定されない限り確認プロンプト（`[y/N]`）を表示。
  - 編集完了後は自動的に再検索を行い、最新の状態を表示してキャッシュ整合性を維持する。

## 6. インストーラーの仕様 (`ttfm_cli.sh`)
- ビルド済みの本体をリリースから取得し、検証してユーザー領域へ配置する。root 権限は使わない
- 対応は Linux x86_64 と macOS Apple Silicon。それ以外はソースからのビルドを案内する
- シェル補完スクリプトは、rc ファイルを変更せずに有効化できるシェルにのみ配置する。それ以外のシェルや PATH の設定は案内に留める
- アンインストールは、インストーラが配置したものだけを削除する。ユーザーデータは明示した場合のみ削除する
